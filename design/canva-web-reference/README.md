## Prompt สำหรับส่งให้แชทพัฒนาเว็บ

> ใช้ภาพตัวอย่าง UI 25 หน้าในโฟลเดอร์นี้หรือสไลด์ Canva ชื่อ “Web Design” เป็น reference ของ **โครงหน้าและองค์ประกอบ** ไม่ต้องคัดลอกสี ชื่อร้าน ชื่อสินค้า หรือรายละเอียดกราฟิกแบบตรงตัว ให้ทำเว็บร้านขาย Digital Product ที่ใช้งานได้จริงด้วยธีมสว่าง รองรับมือถือและคอม โดยมีหน้าลูกค้า 1–18 และหลังบ้านแอดมิน 19–25 ตามชื่อสไลด์ รักษาลำดับการใช้งาน: ค้นหา/กรองสินค้า → ดูรายละเอียด → เพิ่มตะกร้า → ชำระเงิน → ยืนยันผล → ดาวน์โหลดในคลัง และมีประวัติ/ติดตามออเดอร์/ช่วยเหลือ/ตั้งค่าบัญชี แอดมินจัดการสินค้า คำสั่งซื้อ ลูกค้า คำขอช่วยเหลือ การแจ้งเตือน และตั้งค่าร้าน เชื่อมข้อมูลจริงกับ backend ที่มีอยู่ ตรวจสิทธิ์ลูกค้า/แอดมิน และทำสถานะโหลด ว่าง และผิดพลาดทุกหน้าที่เกี่ยวข้อง **ห้ามใช้ภาพตัวอย่างแทนหน้าเว็บที่ทำงานได้จริง**; ต้องทำฟอร์ม ปุ่ม การนำทาง และ API ให้ทำงานได้ ตรวจสอบ responsive และ accessibility ก่อนส่งงาน

SVG เป็นภาพร่างเชิงโครงสร้าง ไม่ใช่ specification ของ backend หรือการชำระเงินจริง ควรอ้างอิงโค้ดและ API ของโปรเจกต์ประกอบเสมอ

สร้างภาพใหม่ได้ด้วย `node design/canva-web-reference/generate.mjs`
